# Visual assets

The README cover, app icon, and five gallery photographs were produced with the built-in image generation tool for this project. The screenshots are captures of the running macOS app connected to an isolated local Garage bucket. `fjord-pan.mp4` is a three-second pan generated from `fjord-dawn.png` with FFmpeg.

## Final image prompts

| Asset | Prompt |
| --- | --- |
| `media/openbucket-hero.png` | Wide GitHub README cover for a native macOS S3 browser: a small translucent frosted glass open bucket holding tidy image and document tiles, deep charcoal background, cyan and lavender rim light, broad negative space, premium minimal 3D rendering; no text, logos, watermark, people, or fake app UI. |
| `AppIcon.appiconset` | Square macOS icon for OpenBucket: one translucent glass bucket with a slightly open top and three stacked object tiles, centered on midnight blue, restrained cyan and lavender lighting, clear silhouette at 32 pixels, important shapes inside the central safe area; no text or extra objects. |
| `alpine-meadow.png` | Photorealistic editorial landscape of a lush alpine meadow, dark pines, pale distant mountains, early morning mist and green texture; no people, buildings, lettering, or watermark. |
| `city-after-rain.png` | Photorealistic editorial architecture at blue hour, warmly lit geometric windows and reflections on wet pavement; no readable signs, people, or watermark. |
| `coastal-cliffs.png` | Photorealistic editorial Atlantic coastal cliffs at golden hour, teal sea and pale surf; no people, buildings, lettering, or watermark. |
| `desert-dunes.png` | Photorealistic editorial sandstone dunes with warm ochre ridges, long soft shadows, and a clear muted sky; no people, vehicles, buildings, or lettering. |
| `fjord-dawn.png` | Photorealistic editorial Nordic fjord at dawn, pale water, layered mountains, warm sunrise, and fine mist; no people, boats, buildings, or lettering. |

The generated icon source was resized to the macOS asset catalog sizes. No generated interface was used in the screenshots.
